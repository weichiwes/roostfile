# 栖档（Roostfile）

一款只在你自己电脑上运行的个人资料馆。接入你选定的文件夹，之后凭记得的一句话就能找回文件，连扫描件里的字也能搜到，按一下快捷键就能把文件交给正在用的程序。

[English](README.md)

![扇面视图](previews/windows/zh-narrow.png)

- **只在你的电脑上运行**：不用注册账号，不收集使用数据，不检查更新，也不会连接互联网。
- **默认不动原文件**：默认不移动、不重命名、不删除。你也可以选择把拖入的文件直接移到资料库，之后随时能移回去。任何内容都不会上传。
- **记得一点就能找到**：搜索文件名、文档正文，以及照片和扫描件里的文字，中英文都支持。

> **当前状态：早期原型。** 还没有安装程序。已在 Windows 11 和 Python 3.12 上测试。macOS 版代码已写好，但还没有在 Mac 上运行过。

## 能做什么

![快速搜索](previews/windows/zh-quick.png)

- **把文件交给小栖**：桌面上站着一个 Q 版助手娘。把文件或文件夹拖给她，她会抱着文件夹读取内容，再按主题放进收藏集，比如“合同”“发票”。默认保存一份副本，原文件留在原处；也可以在设置里改成直接移到资料库，并按主题分好文件夹。点一下能搜索，可以拖到任何位置，也能换成你自己的图片。
- **接入你自己的工具**：内置 MCP 服务。在设置里开启后，AI 助手和工作流就能搜索、读取你的资料库。
- **原位建档或副本归档**：按文件夹选择，随时可以切换。添加的文件夹不会被移动、重命名或删除。
- **新文件到了就知道**：新文件出现时，屏幕顶部弹出一条小提示，可以直接复制或打开。它不抢键盘，全屏游戏和演示时不会出现。
- **把相关文件关联起来**：报价单、合同和现场照片可能分散在不同文件夹。关联一次，它们就会在“关联”页面里排成一组，每个文件都是一张带封面的卡片。找到其中一个就能看到其余的，还能整组复制。选中文件按 `Ctrl L`，或者把一张卡片拖到另一张上就行。栖档也会推荐可能相关的文件，并说明原因。
- **用收藏集归拢文件**：把散落各处的文件按任务收在一起，比如报税，文件本身不移动。搜索后可以全部加入，文件改名后仍在集合里，也能导出成 CSV 清单。
- **随时搜索**：在任何程序里按 `Ctrl Alt K`，弹出一条搜索框。输入线索，按 `Ctrl C`，马上回到原来的窗口，可以直接粘贴文件。
- **搜索名称、正文和标签**：多个词同时生效，能缩小结果。支持中文和英文，包括两个字的中文词和词的一部分。
- **读取照片和扫描件**：截图、文档照片和扫描 PDF 里的中英文都能搜到。使用 Windows 自带的文字识别，在后台运行，不用下载模型。
- **直接写条件**：`最近7天 PDF 合同`、`图片 森林`、`last 7 days pdfs contract` 都会转成筛选条件，并显示出来。没有结果时会尝试相关词，比如用“合同”代替 `contract`，并明确告诉你。
- **按外观浏览**：有扇面、网格和列表三种视图，封面来自文件的真实内容。PDF 显示真实页面。
- **分清版本**：同一文件夹里的 `合同终稿(1)`、`合同终稿-最新`、`合同 final` 会识别为同一份文档，并标出最新版，其他版本点一下就能切换。
- **打开前先确认**：结果显示命中的段落，预览中会高亮每一处命中。PDF 显示真实页面，CSV 和 Excel 显示为表格。
- **找到就能用**：把文件拖进聊天窗口或邮件，或按 `Ctrl C` 再粘贴。始终是复制，不会移动原文件。
- **自动保持最新**：新增和改动的文件几秒后就能搜到。变化由 Windows 通知，只检查变动的文件夹，资料库空闲时不占用磁盘。
- **不靠猜的整理**：侧栏按文件类型和你自己的文件夹逐级浏览，两者都是确定的信息。标签和收藏在更新后仍会保留，文件改名或移动后也会跟着走。
- **接着上次继续**：扇面优先显示你最近打开、复制或拖出过的文件，新文件放在周围。
- **界面语言**：默认英文，可以在设置里切换为简体中文。

## 换成你自己的形象

![小栖的正面全身图](previews/roo.png)

她出现时会挥手打招呼，眼睛会跟着鼠标，会眨眼、呼吸、说话。用鼠标拎起她时，指针就是那只手：捏住衣领，开衫跟着被提上去，双腿悬空，身体随鼠标来回晃。不理她的时候，她会在原地看书、写作业、拍皮球、喝茶或打盹。这只是计时，不会读取你的任何操作。右键菜单可以让她停止玩耍，或把她固定在原位。小栖是分层插画，由这个软件自带的绑定程序驱动，做法和 Live2D 类似，但她不是 Live2D 模型，也没有使用 Live2D 的任何软件。

右键小栖，选择“更换形象”。支持 20 MB 以内的 PNG、JPG、WebP、BMP 和 GIF，GIF 会播放。任何图片都会轻轻浮动、弹跳，图片副本存在资料库里，原图移走也不受影响。

想让每种表情用不同的图，就选择“为每种表情选图片”，再选一个文件夹，里面放 `idle`、`excited`、`working`、`happy` 这几个名字的图片，比如 `happy.png`。没有单独图片的表情用 `idle`。

全屏游戏和演示时小栖会自动隐藏。也可以在她的菜单或设置里关掉，开启“减少动效”后她会保持静止。

## 更改档案位置

档案默认放在程序旁边的 `data` 文件夹。要换地方，在设置里选“更改位置”，再选一个本机文件夹，栖档会在里面新建 `Roostfile` 文件夹，把数据库、保存的副本和设置都复制过去，检查无误后才切换。原始文件不会移动，旧文件夹也会保留，确认没问题后可以自己删除。

选中的文件夹里如果已经有一份档案，栖档会问你要不要切换过去，不会覆盖它。档案放在移动硬盘上时，如果启动时硬盘没接上，栖档会提示你，不会新建空档案。

## 接入你自己的工具

栖档内置 [Model Context Protocol](https://modelcontextprotocol.io) 服务。在设置里打开“允许连接的工具读取这个资料库”，点“复制接入配置”，再粘贴到工具的 MCP 设置里。配置大致如下：

```json
{
  "mcpServers": {
    "roostfile": {
      "command": "C:\\path\\to\\python.exe",
      "args": ["C:\\path\\to\\mcp_server.py", "--data", "C:\\path\\to\\data"]
    }
  }
}
```

| 工具 | 作用 |
| --- | --- |
| `search_files` | 按文件名、正文和标签搜索文件 |
| `read_file_text` | 分段读取文件文字，包括从图片里识别出的文字 |
| `list_collections` | 列出你的收藏集 |
| `list_collection_files` | 列出某个收藏集里的文件 |
| `add_to_collection` | 把文件加入收藏集。需要打开“也允许它们把文件加入收藏集” |
| `list_linked_files` | 列出和某个文件关联的文件 |
| `link_files` | 把文件关联起来。和 `add_to_collection` 用同一个开关 |

它通过标准输入输出通信，不开任何网络连接，也只能接触已在资料库里的内容。两个开关每次请求都会重新读取，所以关掉后立刻生效，连接中的工具也一样。所有工具都不会移动、修改或删除文件。

## 开始使用

需要 Windows 和 Python 3.12 及以上。

```powershell
git clone https://github.com/weichiwes/roostfile.git
cd roostfile
python -m pip install --only-binary=:all: --target .vendor -r requirements-ui.txt
python desktop_app.py --demo
```

`--demo` 会打开一个独立的示例资料库，里面都是虚构文件，可以先随便看看。要管理自己的文件，双击 `start.cmd`，或运行 `python desktop_app.py`。首次打开会推荐常用文件夹，你确认之前不会读取任何内容。界面默认是英文，可以在设置里切换为简体中文。

### 打包便携版

便携版自带 Python 和全部依赖，在什么都没装的电脑上也能运行。解压到任意位置，双击 `start.cmd` 即可，资料库保存在同一个文件夹里。

```powershell
python package_windows.py --python path\to\python-3.12-embed-amd64
```

这会用 python.org 的嵌入版生成 `dist\Roostfile-windows-x64.zip`，约 90 MB。

### macOS

还没有在 Mac 上实测过，可能会有问题。需要 macOS 12 及以上和 Python 3.12 及以上。

```bash
python3 -m pip install --target .vendor -r requirements-ui.txt
./demo.command
```

快捷键是 `⌘ ⌥ K`。文字识别使用 Apple 的 Vision 框架，未下载的 iCloud 文件会被跳过。


## 键盘操作

| 按键 | 作用 |
| --- | --- |
| `Ctrl Alt K` | 快速搜索，在任何程序里都能用，可在设置里修改 |
| `Ctrl K` 或 `Ctrl F` | 搜索 |
| `↓` | 从搜索框进入结果 |
| 在第一条结果上按 `↑` | 回到搜索框 |
| `空格` | 完整预览 |
| `Enter` 或双击 | 打开文件 |
| `Ctrl C` | 复制文件，可直接粘贴 |
| 快速搜索里按 `Ctrl Shift C` | 只复制文字 |
| 右键 | 列出文件的全部操作 |
| `Ctrl R` | 更新档案 |
| `Esc` | 收起预览，再按一次清空搜索 |

快速搜索里，`Enter` 打开文件，`Ctrl C` 复制文件，`Ctrl Enter` 显示所在位置，`Esc` 关闭。

脚本和程序只显示所在位置，不会直接运行。

## 隐私与离线

栖档不用注册账号，不收集使用数据，不检查更新，也不会连接互联网。程序启动时会禁用自身的网络连接，拒绝接入网络文件夹，也不会跟随 SVG 文件和富文本里指向其他电脑的链接。测试时，Linux 上的系统调用跟踪没有记录到任何互联网连接，Windows 上监控程序的网络端点也没有发现连接。这项测试还没有在 Mac 上做过。

程序只读取你接入的文件夹和拖给小栖的文件。她的眼睛会跟随鼠标位置，这个位置不会保存。单独拖入一个文件时，不会读取同一文件夹里的其他文件。连接的工具在你允许之前无法访问资料库；允许之后，它能读取文件文字，是否发送给在线服务取决于那个工具。照片和扫描件里的文字由 Windows 在本机识别，不会上传。关闭窗口后程序会留在托盘，用于快捷键和文件变化通知，可以在设置里关闭；开机启动默认关闭。程序不发起网络请求：没有账号、遥测和更新检查，启动时会阻止 Python socket。这项检查在程序内部，不是防火墙。打开文件时交给系统默认应用处理，其行为由该应用决定。程序拒绝网络路径和映射网络盘，也会跳过云盘占位文件，浏览时不会触发下载。

只有一种情况例外，而且要你亲自开启：通过 MCP 连接的工具能读取文件文字，并可能发送给在线服务。这项功能默认关闭，设置里的开关旁边写明了这一点。

## 局限

搜索靠关键词。没有语义模型，不能识别照片的画面内容，也不能识别音视频里说的话。

- 小栖靠匹配词语分类，并不理解内容。她先看文件名，再看正文，从约 25 个日常主题里选，都对不上时按文件类型放。分错时把文件移出收藏集即可。
- 图片文字识别可能读错形近字，比如“金”和“全”，所以照片里的词有时搜不到。这项功能依赖 Windows 对应语言的文字识别组件，中文和英文 Windows 通常已自带。扫描 PDF 最多读取前 20 页。
- 版本只按同一文件夹里的文件名判断，不比较文件内容。
- PDF 最多提取前 100 页、约 20 万字符。超过 24 MB 的文件只索引名称和文件信息。
- 加密 PDF 和旧版 `.doc/.xls/.ppt` 文件只索引名称和文件信息。
- SVG 文件只索引名称，封面显示为普通样式。因为 SVG 可以引用其他文件，甚至别人电脑上的文件，绘制时会被打开。
- 层级超过 Windows 路径限制的文件夹会被跳过，资料来源页会提示。
- 副本归档不是备份系统，也没有版本历史浏览。
- 数据以普通本地文件保存，没有额外加密，其中也包括从文档里读出的文字，所以资料库文件夹要和文档本身一样注意保管。移除来源时，它的文字会从资料库中清除，但副本会保留，需要时请到 `vault` 文件夹自行删除。
