栖档 Roostfile 0.1.0（早期预览版）

栖档 Roostfile 的第一个可下载版本，还是早期原型。只在你自己的电脑上运行：接入你选定的文件夹，记得一点线索就能找回文件，连照片和扫描件里的字也能搜到。

## 下载和打开（Windows 64 位）

1. 在下面的 Assets 里下载 `Roostfile-windows-x64.zip`（约 90 MB）。不要下载 GitHub 自动附带的 Source code。
2. 解压到你自己的文件夹，比如桌面、文档或 D 盘。不要放进 `C:\Program Files`，那里没有写入权限。不用安装，也不用装 Python。
3. 打开解压出来的 `Roostfile-windows-x64` 文件夹，双击 `start.cmd`。用 Windows 自带的“全部解压缩”时，里面还有一层同名文件夹，再点进去一层。

- 这个版本没有数字签名，第一次打开时 Windows 可能弹出安全提示。确认文件是从这里下载的，就点“运行”，或者“更多信息”→“仍要运行”。如果每次打开都弹：先删掉解压出来的文件夹，在压缩包上右键 →“属性”→ 勾选“解除锁定”→“确定”，再重新解压。
- 界面默认是英文，在设置（Settings）里可以切换成简体中文。首次打开会推荐常用文件夹，你确认之前不会读取任何内容。
- 想先看看效果：双击 `demo.cmd`，会打开一个全是虚构文件的示例资料库。
- 资料库默认保存在这个文件夹里的 `data` 文件夹，在设置里可以换位置。
- 关掉窗口后，程序会留在托盘里，供快捷键和新文件提醒使用；在托盘图标上右键可以退出。

## 能做什么

- **搜正文**：文件名、文档正文都能搜，中英文都行。
- **搜照片和扫描件里的字**：用 Windows 自带的文字识别，在你的电脑上完成，不用下载模型。需要 Windows 带对应语言的文字识别组件，中文和英文 Windows 通常已经自带。扫描 PDF 最多读前 20 页。
- **直接写条件**：比如 `最近7天 PDF 合同`，会变成筛选条件显示出来。
- **分清版本**：同一文件夹里的 `合同终稿(1)`、`合同终稿-最新` 这类文件会认成同一份，并标出最新的那版。
- **随时搜索**：在任何程序里按 `Ctrl Alt K` 弹出搜索框，选中后按 `Ctrl C`，回到原来的窗口直接粘贴。
- **关联成组**：报价单、合同、现场照片关联一次，找到一个就能看到一整组。
- **新文件提醒**：新文件到了，屏幕顶部弹出一条小提示。
- **接入你的 AI 工具**：内置 MCP 服务，在设置里打开后，AI 助手可以搜索、读取你的资料库。默认关闭。
- **把文件交给小栖**：把文件或文件夹拖给桌面上的小栖，她会按合同、发票这类主题放进收藏集。默认另存一份副本，原文件不动。

## 隐私

不用注册账号，不收集使用数据，不检查更新，也不连接互联网。只读取你添加的文件夹和拖给小栖的文件。

只有一个例外，而且默认关闭：在设置里打开 MCP 后，你接入的 AI 工具能读取文件里的文字，会不会发给在线服务，取决于那个工具。

## 已知情况

- 早期原型，只在 Windows 11 上测试过。macOS 版代码写好了，但还没在 Mac 上跑过，这里也没有 Mac 版下载。
- 没有安装程序和自动更新。有新版本时，到仓库的 Releases 页面下载；换新版时，把旧文件夹里的 `data` 文件夹复制到新文件夹（在设置里换过位置的话，再复制 `data-location.txt`）。

**Roostfile 0.1.0 (early preview).** A private file archive that runs only on your computer. Add the folders you choose, then find any file from the clue you remember, even a word inside a photo or a scan.

**Get started (64-bit Windows):** under Assets, download `Roostfile-windows-x64.zip` (about 90 MB), not the Source code archives. Unzip it into a folder of your own, such as Desktop, Documents or another drive, not `C:\Program Files`, which is not writable. Open the `Roostfile-windows-x64` folder (Windows' Extract All adds one more folder of the same name) and double-click `start.cmd`. Nothing to install, and no Python needed.

This build is not signed, so Windows may warn you the first time; choose Run, or More info → Run anyway. If it warns you every time, delete the unzipped folder, right-click the zip → Properties → tick Unblock → OK, and unzip again. The interface starts in English; Settings switches it to Simplified Chinese. `demo.cmd` opens an archive of made-up files to look around first. Your archive is kept in the `data` folder inside this folder by default, and Settings can move it. Closing the window keeps the app in the tray for the shortcut and new-file notices; right-click the tray icon to quit.

**Privacy:** no account, no telemetry, no update check, and it never connects to the internet. Only the folders you add and the files you drop on Roo are read. One exception, off by default: if you turn on MCP, the AI tool you connect can read your files' text and may send it to an online service, depending on that tool.

**Known limits:** an early prototype, tested on Windows 11 only. There is no macOS download yet, no installer and no automatic update. To move to a new version, copy the old folder's `data` folder (and `data-location.txt`, if you moved the archive) into the new one.
